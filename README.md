# seceng.guide

Source for the **DIY Continuous Security** workshop deck, hosted at <https://seceng.guide/>.

A static, single-page slide deck covering practical Continuous Security topics — SAST, DAST, SCA, secrets detection, and AI-assisted code review — aimed at AppSec practitioners, security consultants moving in-house, engineers picking up security responsibilities, and first security hires.

Slide content lives in the numbered markdown files (`1-Intro.md`, `2-SAST.md`, …) and is rendered by [index.html](index.html) with no build step.
